## 📌 About

This repository contains the laboratory programs for **22CAC10N – Deep Learning Lab**.

The experiments are implemented using **Python, TensorFlow, Keras, and PyTorch** and cover fundamental and advanced deep learning concepts including Perceptrons, Multilayer Perceptrons, optimization, regularization, Convolutional Neural Networks, transfer learning, LSTMs, attention mechanisms, BERT, and Generative Adversarial Networks.

## 🎯 Course Objectives

* Understand the fundamental concepts of **Deep Learning** and its applications.
* Evaluate different **Deep Learning methods, models, and algorithms**.
* Analyze and implement **CNNs, RNNs, Transformers, and GANs**.
* Understand the practical applications of modern deep learning architectures.
* Develop and evaluate deep learning models for real-world applications.

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/Bheeshma2234/22CAC10N-Deep-Learning-Lab.git
```

Move into the repository:

```bash
cd 22CAC10N-Deep-Learning-Lab
```

Install the required Python packages:

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow keras torch torchvision
```

## ▶️ Running the Programs

For Python programs:

```bash
python program.py
```

For Jupyter Notebook files:

```bash
jupyter notebook
```

Then open the required `.ipynb` file and execute the cells.
